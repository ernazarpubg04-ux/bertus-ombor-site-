BERTUS OMBOR — sayt fayllari

Fayllar:
- index.html: saytning sahifa tuzilishi va matnlar
- style.css: ranglar, o'lchamlar va dizayn
- script.js: do'konlar va Instagram havolalari

Qanday tahrirlash:
1. script.js faylida stores ro'yxatidan do'kon nomi, manzili va xarita havolasini o'zgartiring.
2. script.js faylida instagramAccounts ro'yxatidagi nom va havolalarni o'zgartiring.
3. Ranglar va ko'rinishni style.css faylining boshidagi :root o'zgaruvchilaridan tahrirlash mumkin.
4. index.html faylidan sarlavha va matnlarni o'zgartirish mumkin.

Saytni internetga chiqarish:
- GitHub repository yarating.
- Uchta faylni (index.html, style.css, script.js) repository bosh sahifasiga yuklang.
- GitHub repository Settings > Pages bo'limidan Deploy from a branch, main va /(root) tanlang.
- Saqlang va GitHub Pages bergan HTTPS manzilni kuting.
- Keyin Telegram BotFather orqali Mini App/Web App URL sifatida shu HTTPS manzilni kiriting.

Eslatma:
Bu statik sayt. Telegram ichida ochilishi uchun u HTTPS orqali ommaga ochiq joylashtirilishi kerak.
